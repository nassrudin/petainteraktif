PRODUCT REQUIREMENT DOCUMENT (PRD)

Nama Produk:
Growth Mindset Journey Map - Platform Petualangan Refleksi Diri Siswa

Versi:
1.0

1. LATAR BELAKANG

Growth Mindset Journey Map merupakan platform digital interaktif yang mengubah lembar refleksi pengembangan diri menjadi pengalaman belajar berbasis petualangan. Sistem ini dirancang untuk membantu siswa mengenali diri, menghadapi tantangan, membangun kepercayaan diri, serta merefleksikan perkembangan pribadi.

Platform ini menggantikan metode worksheet konvensional menjadi journey map digital dengan elemen gamifikasi, progress perjalanan, badge, dan visualisasi perkembangan siswa.

2. TUJUAN PRODUK

Tujuan utama:
- Membantu siswa melakukan refleksi diri secara sistematis.
- Meningkatkan kesadaran siswa terhadap proses belajar dan perkembangan diri.
- Membantu guru memantau perkembangan mindset siswa.
- Menyediakan dokumentasi hasil refleksi siswa dalam bentuk digital.

3. TARGET USER

A. Siswa
- Mengisi perjalanan refleksi diri.
- Melihat perkembangan pribadi.
- Mengunduh hasil journey map.

B. Guru/Admin
- Mengelola akun siswa.
- Melihat hasil refleksi siswa.
- Mengunduh dan menyimpan laporan.

4. KONSEP UTAMA

Produk menggunakan konsep "Adventure Journey Map".

Siswa akan melewati 8 tahap perjalanan:

1. Mengenali diri dan percaya diri.
2. Menentukan tantangan.
3. Mengidentifikasi hambatan.
4. Menentukan langkah kecil.
5. Mengelola kritik.
6. Belajar dari orang lain.
7. Melakukan refleksi usaha.
8. Membuat komitmen perubahan.

Setiap tahap memiliki:
- Deskripsi misi.
- Form pertanyaan.
- Status penyelesaian.
- Reward/progress.

6. FUNCTIONAL REQUIREMENTS

6.1 Authentication

Sistem harus menyediakan:
- Login siswa.
- Login admin.
- Logout.
- Manajemen akun pengguna.

Role:
- Student.
- Admin/Teacher.


6.2 Student Dashboard

Menampilkan:
- Nama siswa.
- Kelas.
- Progress perjalanan.
- Tahap yang sudah selesai.
- Tahap berikutnya.

6.3 Interactive Journey Map

Sistem menampilkan peta perjalanan visual.

Fitur:
- Animasi perpindahan tahap.
- Unlock tahap berikutnya.
- Status selesai/belum selesai.
- Badge pencapaian.

6.4 Reflection Form

Setiap tahap memiliki form.

Jenis input:
- Text area.
- Skala angka.
- Checklist.
- Catatan pribadi.

6.5 Result Generator

Setelah selesai:

Sistem membuat:
- Journey Map image.
- PDF report.

Isi:
- Identitas siswa.
- Semua jawaban.
- Skor refleksi.
- Pesan motivasi.

6.6 Download

Siswa dapat:
- Download PNG.
- Download PDF.

6.7 Google Drive Integration

Sistem dapat:
- Membuat gambar hasil otomatis.
- Mengupload ke Google Drive.
- Menyimpan URL file.

Struktur folder:

Growth Mindset Journey/
|
|- Kelas
|
|- Nama Siswa.png


6.8 Admin Dashboard

Fitur:

Monitoring:
- Jumlah siswa.
- Progress siswa.
- Status penyelesaian.

Data:
- Nama siswa.
- Kelas.
- Hasil refleksi.
- File hasil.

7. NON FUNCTIONAL REQUIREMENTS

Performance:
- Halaman terbuka maksimal 3 detik.
- Mendukung minimal 500 pengguna.

Security:
- Password terenkripsi.
- Hak akses berdasarkan role.
- Data siswa terlindungi.

Compatibility:
- Desktop.
- Tablet.
- Mobile browser.
