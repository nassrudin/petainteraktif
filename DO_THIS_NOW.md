## 🆘 IF IT FAILS

### Quick Checks:

1. **Check Actions Tab:**
   - Any red X? Click it to see error log
   - Common issue: Build failed

2. **Build Error?**
   ```bash
   npm run build
   # Check console errors
   # Fix locally then re-push
   git add . && git commit -m "fix: resolve build errors"
   git push
   ```

3. **Site Shows 404?**
   - Wait longer (DNS propagation can take 5 min)
   - Hard refresh browser (Ctrl+F5)
   - Clear cache

**Full Troubleshooting**: See `MANUAL_SETUP_GITHUB_PAGES.md`
