# Growth Mindset Journey Map Percaya Diri

> **Delapan pos untuk mengubah rasa ragu menjadi keberanian bertumbuh, media layanan bimbingan klasikal kelas X**

🌐 **Aplikasi Online (Live Demo):** [https://nassrudin.github.io/petainteraktif/](https://nassrudin.github.io/petainteraktif/)

Platform web interaktif gamifikasi untuk layanan bimbingan klasikal Bimbingan dan Konseling (BK) siswa kelas X. Mengembangkan pola pikir bertumbuh (*Growth Mindset*) serta mengikis keraguan diri (*self-doubt*) menjadi keberanian belajar melalui 8 pos petualangan bertahap.

---

## 🧭 Alur Pembelajaran & Pengisian Pos

Sesuai rancangan bimbingan klasikal 2 etape (siklus bertahap):

> **"Isi pos 1 sampai 4 pada pertemuan ini, lalu coba langkahmu selama satu minggu. Pos 5 sampai 8 diisi setelah kamu mencobanya. Tidak ada jawaban benar atau salah, tulis sejujurnya tentang dirimu."**

### 📍 Etape 1: Mengenali diri dan menghadapi tantangan (Pertemuan 1)
- **1. Potret percaya diri saya (`Titik mulai`):**
  - Situasi kurang percaya diri
  - Saat situasi itu terjadi: *Saya berpikir*, *Saya merasa*, *Saya lalu*
  - Skala percaya diri: `1 (Belum berani) — 5 (Sangat berani)`
  - Contoh: *"Saya tahu jawabannya, tapi tangan saya tidak pernah terangkat saat guru bertanya."*
- **2. Tantangan yang saya pilih (`Challenge`):**
  - Satu tantangan yang paling ingin ditaklukkan
  - Hal yang membuat terasa berat
  - Tukar kalimat: Dari *"Saya tidak bisa"* menjadi *"Saya belum bisa... dan saya sedang belajar dengan cara..."*
  - Kalimat untuk diri sendiri saat takut mencoba
- **3. Hambatan di jalan saya (`Obstacles`):**
  - Hambatan dari dalam diri (pikiran, perasaan)
  - Hambatan dari luar (lingkungan, orang lain)
  - Mengapa hambatan itu muncul & cara melewatinya
  - Kalimat untuk diri sendiri saat ingin menyerah
- **4. Langkah kecil saya (`Effort`):**
  - Tiga langkah menuju tantangan dari yang paling mudah
  - Rencana aksi: Mulai tanggal, agar konsisten, yang membantu
  - Kalimat apresiasi untuk diri sendiri setiap selesai satu langkah

---

### ⏳ Praktik Mandiri Selama Satu Minggu
Siswa mempraktikkan langkah kecil yang telah dirancang di kehidupan nyata sekolah.

---

### 📍 Etape 2: Belajar dari sekitar dan bertumbuh (Pertemuan 2)
- **5. Saat saya dikritik (`Critiques`):**
  - Masukan yang pernah diterima dari guru, teman, atau keluarga
  - Memilah bagian yang *Membangun* vs *Menjatuhkan*
  - Hal yang diambil dan diperbaiki
  - Komitmen cara merespons kritik mulai sekarang
- **6. Belajar dari orang lain (`Success of others`):**
  - Sosok yang dikagumi keberaniannya (tokoh, guru, kakak kelas, teman, keluarga)
  - Hal konkret yang dilakukan sosok tersebut sehingga terlihat percaya diri
  - Satu hal yang bisa ditiru minggu ini
  - *Ingat:* Keberhasilan orang lain bukan ukuran kegagalan saya. Itu bukti bahwa hal itu bisa dicapai.
- **7. Melihat kembali usaha saya (`Refleksi`):**
  - Hal yang sudah berhasil setelah mencoba satu minggu
  - Bagian yang masih kurang berhasil dan alasannya
  - Penemuan hal baru tentang diri sendiri & perubahan kecil yang dirasakan
- **8. Komitmen dan target saya (`Garis akhir`):**
  - Target konkret satu minggu ke depan (3 target)
  - Skala keyakinan terhadap perubahan diri: `1 (Belum yakin) — 5 (Sangat yakin)`
  - Ikrar komitmen kesungguhan diri

## ⚡ Fitur Utama

1. **Akses Langsung Siswa (Tanpa Akun):**
   - Siswa tidak perlu membuat akun, email, atau menghafal password.
   - Cukup memasukkan **Nama Lengkap** dan memilih **Kelas** (misal: `X-1`, `X-2`, dst.) sebelum mulai bertualang.
   - Sesi tersimpan otomatis di perangkat lokal (*Local Storage*).

2. **Peta Petualangan Interaktif (*Interactive Journey Map*):**
   - Jalur petualangan visual dengan pulau-pulau pos refleksi (*S-curve map*).
   - Sistem *unlock* bertahap pos demi pos untuk memastikan refleksi mendalam.
   - Efek perayaan konfeti (*Canvas Confetti*) saat pos berhasil diselesaikan.

3. **Dokumen Hasil Belajar & Ekspor Slide PPT (16:9 Landscape):**
   - Format unduh/cetak PDF disesuaikan ke rasio **PPT 16:9 widescreen landscape** (5 slide presentasi bersih siap tampil di depan kelas tanpa elemen administratif yang mengganggu):
     - **Slide 1:** Cover Presentasi (Judul, Nama Siswa, Kelas, Tanggal, & Pesan Diri).
     - **Slide 2:** Etape 1 Bagian 1 (Pos 1: Potret Percaya Diri & Pos 2: Tantangan Pilihan).
     - **Slide 3:** Etape 1 Bagian 2 (Pos 3: Hambatan di Jalan & Pos 4: Langkah Kecil).
     - **Slide 4:** Etape 2 Bagian 1 (Pos 5: Saat Dikritik & Pos 6: Belajar dari Orang Lain).
     - **Slide 5:** Etape 2 Bagian 2 (Pos 7: Melihat Usaha, Pos 8: Komitmen Target, & Tanda Tangan).
   - Mode interaktif slide per slide di layar atau mode seluruh slide.
   - Sesuai dengan soal-soal revisi terbaru kurikulum Etape 1 & Etape 2.

4. **Penyimpanan Otomatis Google Drive & Pengaturan Link di Admin:**
   - Ketika siswa menyelesaikan seluruh 8 pos, berkas refleksi **secara otomatis tersimpan dan terhubung ke Google Drive** tanpa perlu mengklik tombol upload manual (tombol manual telah dihilangkan).
   - Link folder Google Drive dapat diatur dan diubah kapan saja oleh guru di **Dashboard Admin -> Pengaturan Drive**.
   - Tautan bawaan yang terpasang: `https://drive.google.com/drive/folders/1Slmi-qS--PbmWZh7KzFoMVG3iE5QqD_Z?usp=sharing`.
   - **Google Apps Script Webhook:** Disediakan skrip `google-apps-script-sync.js` dan kolom input URL Webhook di dashboard guru agar setiap siswa yang tuntas 8 pos dapat langsung mengirim berkas JSON refleksi ke folder Google Drive tujuan secara real-time.

5. **Portal Guru / Admin Terpisah:**
   - Guru BK dapat langsung login ke **Dashboard Guru / Admin** secara mandiri tanpa memasuki alur siswa.
   - Autentikasi berbasis username & password bawaan (`admin` / `admin123`).
   - **Fitur Ubah Username & Password:** Guru dapat mengganti username dan password langsung di dashboard admin dengan verifikasi password lama.
   - **Kelola Data Siswa:** Hapus data per siswa atau reset progres jika diperlukan.
   - Monitoring komprehensif: rekap seluruh siswa, filter berdasarkan kelas, pencarian nama, inspeksi jawaban detail 8 pos, dan ekspor rekapitulasi data format CSV.

## 🛠️ Tech Stack & Topology

- **Frontend Core:** React 19, TypeScript 5.7, Vite 6.2
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React (`lucide-react`)
- **Gamification & Rendering:** Canvas Confetti, HTML5 Canvas 2D Rendering
- **Persistence:** Browser `localStorage` (isolasi session siswa, rekap journey, dan auth admin)

## 🚀 Panduan Instalasi & Menjalankan Aplikasi

### Kebutuhan Sistem
- Node.js (v18 atau lebih baru disarankan)
- npm / yarn / pnpm

### Langkah Menjalankan
```bash
# 1. Masuk ke direktori proyek
cd "D:\DATA PROJECT\petainteraktif"

# 2. Instal dependensi (jika belum)
npm install

# 3. Jalankan development server
npm run dev

# 4. Build untuk produksi
npm run build

# 5. Preview hasil build
npm run preview
```
